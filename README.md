# mdlingo

We made mdlingo so clinicians can learn simple instructions and questions in their patients' languages, and use them without waiting for an interpreter. Search a phrase, show the translation on the screen, and use the pronunciation to practice saying it. The Quiz tab tests you on the phrases. There are 2,142 phrases across 14 specialties in 10 languages.
